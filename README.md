# [iinava.dev.co](https://iinava.dev.co)

Personal portfolio, blog, and shadcn registry of Navaneeth B, a Software Engineer building scalable web applications.

→ Live site: [iinava.dev.co](https://iinava.dev.co)

## Overview

### Stack

- Next.js 16
- Tailwind CSS v4
- shadcn/ui

### Featured

- Light/Dark themes
- vCard integration
- SEO optimized ([JSON-LD schema](https://json-ld.org), sitemap, robots)
- AI-ready with [/llms.txt](https://llmstxt.org)
- Spam-protected email
- Installable as PWA
- Analytics with [OpenPanel](https://openpanel.dev)

### Content

Centralized document system powered by MDX:

- Unified content layer for blog posts and component docs
- Category-based content organization
- Raw `.mdx` endpoints for AI readability
- Dynamic OG images for rich link previews
- RSS feed for content distribution

### Registry

Reusable components, hooks, and blocks distributed through a custom registry powered by the [shadcn CLI](https://ui.shadcn.com/docs/cli).
